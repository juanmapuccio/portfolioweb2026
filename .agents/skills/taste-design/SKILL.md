# Skill: Taste & Visual Excellence

## Criterios de Calidad Estética
1. **Evitar lo Genérico:** Prohibido usar paletas predeterminadas sin curaduría, bordes toscos o sombras desproporcionadas.
2. **Jerarquía Visual Inquebrantable:**
   - Contraste deliberado entre titulares (fuente display contundente) y texto secundario (neutro, legible).
   - Espaciado rítmico (escala de 4px / 8px).
3. **Superficies y Profundidad:**
   - Capas oscuras sutiles con diferentes niveles de elevación (Obsidian `#0a0c10` -> `#12161f` -> `#181e2b`).
   - Micro-bordes sutiles de 1px con opacidad baja para delimitar tarjetas.
4. **Estados Interactivos Elegantes:**
   - Feedback táctil y visual inmediato en `:hover`, `:active` y `:focus-visible`.
   - Transiciones rápidas y con curvas de aceleración naturales (`ease-out`, 150-200ms).
