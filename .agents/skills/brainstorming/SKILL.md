# Skill: Brainstorming & Product Refinement

## Cuándo Utilizar Este Skill
- Al explorar nuevas funcionalidades, replantear la arquitectura o definir el tono y copywriting de una sección clave.
- Cuando haya más de un camino viable y se deba contrastar valor de negocio, complejidad y experiencia de usuario.

## Principios Fundamentales
1. **Claridad del Problema Antes que la Solución:** Nunca proponer código o componentes sin tener claro qué dolor del usuario o del reclutador se está resolviendo.
2. **Pregunta Focalizada:** Formular como máximo una sola pregunta precisa a la vez. No aturdir al usuario con cuestionarios extensos.
3. **Trade-offs Explícitos:** Toda elección técnica o visual tiene ventajas y desventajas. Exponerlas con transparencia técnica.
4. **Pensamiento Crítico y Verificación:** Validar siempre con hechos y pruebas en código antes de aceptar asunciones técnicas.
