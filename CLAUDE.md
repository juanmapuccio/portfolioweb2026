# Reglas de este proyecto

## Comunicación sobre git / GitHub / CI / tests

Todo lo relacionado a git local, GitHub (ramas, commits, push, Pull Requests),
tests, typechecks (`astro check`, `tsc`, etc.) y CI debe explicarse o nombrarse
en **español simple y fácil de entender**, no en jerga técnica sin traducir.

Esto aplica a lo que se le dice al usuario (resúmenes, explicaciones), no a
los artefactos técnicos en sí: los mensajes de commit, el cuerpo de los PRs,
el YAML de CI y los nombres de tests siguen en inglés salvo pedido explícito.
